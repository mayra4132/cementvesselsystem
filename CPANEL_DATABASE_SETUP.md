### 1. Overview & Prerequisites

The **VIGOR Smart Port Operations** platform connects to a relational MySQL/MariaDB database to store:
* Corporate user accounts and role-based permissions (`Admin`, `Management`, `Operations`, `Viewer`)
* Operational activity and audit logs
* Vessel fleet specifications and voyage cycles
* Pneumatic discharge throughput readings and berth releases
* Delay events and equipment logs

**Prerequisites:**
* Access to Turkys Group cPanel (`https://your-domain:2083` or `cpanel.turkysgroup.co.tz`)
* phpMyAdmin access
* Database credentials privileges

---

### 2. Step 1: Create the MySQL Database

1. Log in to your **cPanel Dashboard**.
2. Under the **Databases** section, click **MySQL Databases**.
3. Under **Create New Database**:
   * Enter a database name suffix, e.g., `vigor_port` (full name will be `cpaneluser_vigor_port`).
   * Click **Create Database**.
   * Note the full database name generated by cPanel.

---

### 3. Step 2: Create and Assign Database User

1. In the **MySQL Databases** screen, scroll down to **Add New User**:
   * **Username**: `vigor_user` (full username will be `cpaneluser_vigor_user`).
   * **Password**: Generate a high-entropy password (e.g. 24+ characters using letters, numbers, and symbols).
   * Click **Create User**.
2. Scroll to **Add User To Database**:
   * Select User: `cpaneluser_vigor_user`
   * Select Database: `cpaneluser_vigor_port`
   * Click **Add**.
3. On the **Manage User Privileges** page:
   * Check **ALL PRIVILEGES** (specifically `SELECT`, `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `ALTER`, `INDEX`, `REFERENCES`).
   * Click **Make Changes**.

---

### 4. Step 3: Enable Remote MySQL Access (for Vercel)

Since the frontend application runs on Vercel's global edge infrastructure, cPanel's MySQL server must permit remote TCP connections from Vercel:

1. In cPanel, navigate to **Databases → Remote MySQL**.
2. Under **Add Access Host**:
   * **Option A (Recommended for Vercel dynamic IPs)**: Enter `%` in the host field to allow connections from any authenticated client.
     > *Security Note:* The database is strictly protected by MySQL username and high-entropy password authentication.
   * **Option B (Proxy approach)**: If corporate security policy forbids wildcard hosts, deploy a Node.js proxy within the cPanel VPS or use an SSH tunnel / fixed IP gateway.
3. Click **Add Host**.
4. Ensure your server firewall (CSF / iptables / AWS Security Group) allows inbound TCP traffic on port **3306**.

---

### 5. Step 4: Execute Schema & Seed Migrations

1. Return to the main cPanel screen and open **phpMyAdmin**.
2. In the left panel, click your database (`cpaneluser_vigor_port`).
3. Click the **Import** tab in the top navigation bar.
4. Under **File to Import**, click **Choose File**:
   * Select `/database/schema.sql` from this repository.
   * Format: `SQL`.
   * Click **Import** (or **Go**).
   * Verify all 10 relational tables are successfully created:
     - `roles`
     - `users`
     - `vessels`
     - `berths`
     - `vessel_visits`
     - `operational_readings`
     - `delays`
     - `upcoming_calls`
     - `system_settings`
     - `activity_logs`
5. Repeat the Import step for `/database/demo_seed.sql`:
   * Upload `/database/demo_seed.sql`.
   * Click **Import**.
   * This seeds the baseline fleet (`MV VIGOR 01`, `02`, `03`), Berth B01 telemetry, and 4 authorized `@turkysgroup.co.tz` staff accounts.

---

### 6. Step 5: Connection String Configuration

Add these parameters to your production environment variables (on Vercel or your `.env` file):

```ini
# Production cPanel Database Configuration
DB_HOST=cpanel.turkysgroup.co.tz     # Or the static IP of your cPanel server
DB_PORT=3306
DB_USER=cpaneluser_vigor_user
DB_PASSWORD=YourSecurePasswordHere
DB_NAME=cpaneluser_vigor_port
DB_CONNECTION_LIMIT=10

# Security Secret for JWT Authentication
SESSION_SECRET=turkys_group_vigor_enterprise_secret_2025_prod_key
```

### 7. Step 6: Health Verification & Troubleshooting

1. **In-App Health Diagnostic:**
   * Open the VIGOR application in your browser.
   * Sign in with `admin@turkysgroup.co.tz`.
   * Navigate to **Administration → cPanel MySQL Integration**.
   * Click **Test Connection**.
   * When connected, the engine status will display `MySQL Connected` with round-trip latency.

2. **Command-Line Verification:**
   From a terminal outside the server, verify network connectivity:
   ```bash
   mysql -h cpanel.turkysgroup.co.tz -P 3306 -u cpaneluser_vigor_user -p cpaneluser_vigor_port
   ```

3. **Common Issues & Resolutions:**
   * **Host 'xxx' is not allowed to connect to this MySQL server (Error 1130):**
     * Fix: Add `%` or your IP to cPanel **Remote MySQL**.
   * **Connection timed out:**
     * Fix: Verify with host support that port `3306` is open in the server's CSF/firewall.
   * **Access denied for user:**
     * Fix: Confirm the cPanel username prefix (`cpaneluser_`) is included in `DB_USER`.

### Automated Backup Strategy

To ensure zero operational disruption:
1. In cPanel, navigate to **Cron Jobs**.
2. Schedule a daily database dump at midnight EAT:
   ```bash
   mysqldump -u cpaneluser_vigor_user -p'YourPassword' cpaneluser_vigor_port | gzip > ~/backups/vigor_db_$(date +\%F).sql.gz
   ```
3. Retain daily backups for 30 days and store off-site weekly archives.
